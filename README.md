# ELT 121 Language Policy & Planning Reviewer

A responsive, mobile-friendly static study site for ELT 121 with **277 questions** and two practice modes: **Identification** (type the answer) and **Multiple Choice** (select one of four options). The question bank is filterable by topic and can be shuffled.

## Source alignment
- The academic question bank is based on the updated five-page ELT 121 reviewer PDF.
- **History / Philippine contexts** follows the Philippine-period summaries on page 5: Spanish Colonial, American Colonial, Commonwealth / Japanese, Post-Independence / Bilingual Education, and MTB-MLE.
- The examples from Peru, Bolivia, and Māori/New Zealand cited on page 4 are kept in a separate **Multilingual Policy Examples** topic; they are not mixed into the Philippine history topic.
- The language-ideology scenarios on page 4 are grouped under **Language Ecology & Ideology**.
- The single Genesis bonus question was kept because it was explicitly requested earlier; it is the only custom question not from the PDF.

## Run locally
Open `index.html` in a modern browser. No dependencies or build tools are needed.

## Publish with GitHub Pages
1. Upload `index.html` to the root of your existing repository, replacing the older file.
2. Commit the change.
3. Keep GitHub Pages set to **Deploy from a branch**, branch `main`, folder `/(root)`.
4. Open the Pages URL shown in repository settings after deployment completes.

All quiz code runs in the browser, so no server, account, API key, or internet connection is needed after the page is loaded.
